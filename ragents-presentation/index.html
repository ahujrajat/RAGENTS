What is RAGENTS?

Ragents comes from "Rage Agents" — one of two broad agent archetypes we use alongside Sage Agents. Ragents are high-energy SDLC accelerators that push velocity, unblock teams, and drive rapid exploration. In contrast, Sagents help keep the sanity: they focus on responsible AI, best practices, guardrails, and sustainable delivery.

The RAGENTS library brings these accelerators into your workflow, working seamlessly with GitHub Copilot and Claude Code, with a dedicated VS Code Sidebar to browse, preview, and download AI assets.

Categorized View

Easily browse Agents, Instructions, Prompts, and Skills in a structured tree.

Community & Custom

Access both public community assets and verified internal custom assets.

One-Click Download

Instantly copy assets to .github/ or .claude/ folder.

Dual Platform

Supports both GitHub Copilot and Claude Code with automatic directory mapping.

How to Use

1

Open Activity Bar

Click the RAGENTS icon in the VS Code Activity Bar.

2

Browse & Preview

Expand categories. Click an item to preview its content in the editor.

3

Choose Platform

Select GitHub Copilot (.github/) or Claude Code (.claude/) as your target.

4

Download to Workspace

Click the download icon. Multi-file skills are auto-bundled for Claude Code.

5

Engage

Use downloaded assets with Copilot Chat, Claude Code slash commands, or @ragents /use.

Instructions and Skills are currently Public-only; Agents and Prompts include both Custom and Public assets.
